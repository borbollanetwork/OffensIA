# OffensIA v1.2 — Plan 2.5-B: Backbone Data-Loss Fix + Server-Side Digest

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the executor checkpoint from clobbering assessment state (a silent data-loss bug), and add a deterministic, no-LLM digest to tool results so the model reads a compact structured summary instead of raw output dumps (token economy), with raw always preserved in the evidence store.

**Architecture:** (1) Split persistence: assessment state stays in `state.json` (owned by `core/state.py`); the executor writes its checkpoint to a separate `executor-checkpoint.json`, and records the terminal action's sequence (not the intent's). (2) A pure `core/digest.py` extracts a bounded, deterministic digest (status codes, titles, tech, params, ports, anomalies) from raw tool output; the MCP tools attach `digest` to their result and keep raw in the evidence store; `offensia_recon_crawl` returns the digest + a small bounded preview + `evidence_id` instead of dumping the full page content into context. The model pulls full raw on demand via `offensia_evidence_get`.

**Tech Stack:** Python 3.11+, stdlib only, `mcp` (pinned `>=1.2,<2`), pytest/ruff/mypy. Reference engine (stdlib HTTP) for dev/self-test.

**Spec:** `docs/specs/2026-09-23-offensia-v1.2-autonomous-core.md` + accepted `melhoria.md` items §3.1 (state/checkpoint split, data-loss), §3.2 (checkpoint terminal seq), §2.2/§12 (keep only summary + evidence refs in LLM context — realized here as a deterministic server-side digest).

## Global Constraints

- Python 3.11+; stdlib only; no new dependency; `mcp` pin unchanged.
- **No data loss:** the executor checkpoint MUST NOT be written to the same file as assessment state. Assessment fields (`scope`, `discoveries`, `hypotheses`, `pending_tests`, `pending_validation`, `coverage`, `findings`) survive any number of `run_job` calls.
- **Digest is deterministic and LLM-free:** pure functions over raw bytes/str; same input → same digest; bounded output (cap list lengths and string sizes). No network, no model calls.
- **Raw is never lost:** raw output continues to be stored in the evidence store; the digest augments, never replaces, the stored evidence. The model can always fetch raw via `offensia_evidence_get(evidence_id)`.
- Adapters/oracles never raise into the MCP layer (except `CapExceeded`, already handled).
- Backward compatible: existing assessments and `findings.json`/`state.json` still load; a `state.json` that was previously clobbered must not crash the loader.
- Run `ruff check .`, `mypy offensia`, `pytest -q` green before each task's commit. Baseline is 128 passing on `main` (7210f79) — actually branch from current `main` HEAD.

## Review Focus

- **Old clobbered `state.json`** (an assessment whose `state.json` currently holds only executor keys from the pre-fix collision) must still load without raising — defaults fill missing assessment fields. (Task 1)
- **Crash between `run_job` and a later state read** must preserve assessment fields — a regression test runs a job then asserts discoveries/hypotheses survive. (Task 1)
- **Digest on adversarial/garbage output** (binary, huge, empty, non-HTTP) must not raise and must stay bounded. (Task 2)
- **Recon token economy**: `offensia_recon_crawl` must not place the full page body in its returned dict; only a bounded preview + digest + `evidence_id`, with full raw resolvable via evidence. (Task 3)
- **Untrusted content still fenced**: the recon digest/preview shown to the model stays wrapped/marked as untrusted; a digest field derived from target content is data, never instructions. (Task 3)

```python
"""Deterministic, LLM-free digest of raw tool output.

The model reads this compact structured summary instead of raw dumps; the raw
artifact stays in the evidence store and is fetched on demand. Pure functions,
bounded output, never raise on adversarial input.
"""
from __future__ import annotations

import re

_STATUS = re.compile(r"HTTP/\d(?:\.\d)?\s+(\d{3})")
_TITLE = re.compile(r"<title[^>]*>(.*?)</title>", re.IGNORECASE | re.DOTALL)
_PARAM = re.compile(r"[?&]([A-Za-z0-9_.\-]{1,40})=")
_LINK = re.compile(r"<a\s[^>]*href=", re.IGNORECASE)
_FORM = re.compile(r"<form\b", re.IGNORECASE)
_PORT = re.compile(r"^\s*(\d{1,5}/(?:tcp|udp))\s+open\s+(\S+)?\s*(.*)$", re.MULTILINE)
_TECH_HEADERS = re.compile(r"(?im)^(?:Server|X-Powered-By|X-AspNet-Version|Via):\s*(.+)$")
_TECH_MARKERS = (
    ("WordPress", r"wp-content|wp-includes"), ("Django", r"csrfmiddlewaretoken"),
    ("Laravel", r"laravel_session|XSRF-TOKEN"), ("Express", r"(?i)x-powered-by:\s*express"),
    ("React", r"__REACT_DEVTOOLS|data-reactroot"),
)
_ANOMALY = (
    ("sql_error", r"SQL syntax|SQLSTATE|ORA-\d{5}|psql:|mysql_fetch"),
    ("stack_trace", r"Traceback \(most recent call last\)|at [\w.$]+\([\w.]+:\d+\)"),
    ("server_error", r"HTTP/\d(?:\.\d)?\s+5\d{2}"),
    ("debug_leak", r"(?i)DEBUG\s*=\s*True|X-Debug|Whoops!"),
)
_CAP_STR = 200


def _u(seq, n):
    out, seen = [], set()
    for x in seq:
        if x in seen:
            continue
        seen.add(x)
        out.append(x[:_CAP_STR] if isinstance(x, str) else x)
        if len(out) >= n:
            break
    return out


def summarize(kind: str, raw, *, max_items: int = 20) -> dict:
    if isinstance(raw, bytes):
        n = len(raw)
        text = raw.decode("utf-8", errors="replace")
    else:
        text = raw or ""
        n = len(text.encode("utf-8", errors="replace"))
    out: dict = {"kind": kind, "bytes": n}
    if not text:
        return out
    codes = sorted({int(m) for m in _STATUS.findall(text)})
    if codes:
        out["status_codes"] = codes[:max_items]
    titles = _u((t.strip() for t in _TITLE.findall(text) if t.strip()), max_items)
    if titles:
        out["titles"] = titles
    tech = list(_TECH_HEADERS.findall(text))
    tech += [name for name, pat in _TECH_MARKERS if re.search(pat, text)]
    tech = _u((t.strip() for t in tech if t.strip()), max_items)
    if tech:
        out["tech"] = sorted(tech)
    params = _u(sorted(set(_PARAM.findall(text))), max_items)
    if params:
        out["params"] = params
    ports = []
    for portproto, svc, extra in _PORT.findall(text):
        label = f"{portproto} {svc or ''} {extra or ''}".strip()
        ports.append(label[:_CAP_STR])
    ports = _u(ports, max_items)
    if ports:
        out["ports"] = ports
    links = len(_LINK.findall(text))
    if links:
        out["links"] = links
    forms = len(_FORM.findall(text))
    if forms:
        out["forms"] = forms
    anomalies = [name for name, pat in _ANOMALY if re.search(pat, text)]
    if anomalies:
        out["anomalies"] = anomalies
    return out
```
